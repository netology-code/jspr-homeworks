# Установка IDE

Рекомендуем работать над заданиями в среде разработки OpenIDE.
Установка OpenIDE выполняется стандартным образом и не требует специфичных навыков. Процесс установки аналогичен установке других программ.

Полная инструкция по установке OpenIDE доступна в официальном руководстве:
[https://openide.ru/documents/OpenIDE_Rukovodstvo_po_ustanovke_2025.pdf](https://openide.ru/documents/OpenIDE_Rukovodstvo_po_ustanovke_2025.pdf).

Вы можете использовать альтернативную среду разработки Giga IDE, обеспечивающей необходимый базовый функционал для работы с проектами.

### Установка Open IDE

1. Скачайте дистрибутив OpenIDE: https://openide.ru/ .
2. Запустите установочный файл и следуйте инструкциям мастера установки, оставляя параметры по умолчанию.
3. После завершения установки запустите OpenIDE.
При первом запуске среда автоматически определит установленные версии JDK и предложит выбрать подходящую.

### Работа в Giga IDE
В качестве альтернативной интегрированной среды разработки предлагаем Giga IDE.
Для начала работы выполните следующие действия:
1. Скачайте и установите Giga IDE: [https://gitverse.ru/features/gigaide/](https://gitverse.ru/features/gigaide/).
2. Создайте новый проект, используя настройки по умолчанию.
3. Проект, созданный по умолчанию, может быть запущен без дополнительной конфигурации. Перейдите в настройки среды разработки и выберите пункт Download JDK.
4. В списке доступных версий выберите Microsoft OpenJDK 21 и завершите установку.
После загрузки JDK проект готов к работе и может быть запущен стандартными средствами IDE.
